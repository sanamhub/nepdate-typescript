### T0-02 Generator skeleton (`scripts/codegen.ts`)
Run as `node scripts/codegen.ts` (Node's type stripping, so only erasable syntax). Reads
`shared/data/calendar/bs-calendar.json`, checks 299 years × 12 lengths in 29..=32, writes
`packages/nepdate/src/calendar.gen.ts` with the header
`// Generated by scripts/codegen.ts. DO NOT EDIT.` and, for now, `MIN_YEAR` and `MAX_YEAR`.
Deterministic output that passes `biome format`. `--check` regenerates in memory, compares with
the file on disk and exits 1 on any difference. The patro output is added in T4-01.
AC: running it twice gives byte-identical files; changing one character of `calendar.gen.ts` makes
`--check` exit 1.

### T0-03 CI script (`scripts/ci.ts`)
Runs the gates in ADR-0004 in order with `node:child_process`, printing each command, stopping at
the first failure, ending with one summary line (`ci: N/N gates passed`, or
`ci: failed at gate N (<name>)`). Gate 6 is code in this script, not a shell tool. Gate 10 is
added in T5-01, so T0 has 9 gates.
AC: exits non-zero when a file is not formatted; exits non-zero when `"nepdate-patro"` is added to
`packages/nepdate/package.json` `dependencies` (gate 6); prints `ci: 9/9 gates passed` on a clean
checkout.

### T0-04 Test scaffolding
`packages/nepdate/test/vectors.ts`: a helper that reads a TSV or CSV from `shared/spec/vectors/`
by `new URL("../../../shared/spec/vectors/<file>", import.meta.url)` and returns rows as objects
keyed by the header line. `packages/nepdate/test/catalog.ts`: `catalogRows(phase)` returns the rows
of `shared/spec/vectors/csharp-tests/catalog.tsv` tagged with that phase, and
`checkCatalog(phase, cases)` is one Vitest test per row that runs `cases[row.id]` or, for a
deviation entry `{ deviation: "D-04" }`, records a skip with that id (roadmap, "C# test catalogue").
A missing id fails with the id in the message. One smoke test in each package.
AC: the helper returns 7176 rows for `month-boundaries.csv`; `catalogRows` returns more than 0 rows
for phase 1 (if `catalog.tsv` is missing from `shared/`, the sync is broken: stop and tell the
human).
